# Linux beta

This branch (`linux/beta`) builds the personal, offline Cardbe app from v1.7.0. It adds Linux compatibility fixes and a Debian package workflow. It contains no enterprise service, enterprise UI, or account requirement.

## Changes

- Update the locked `tauri-plugin-deep-link` dependency to 2.6.3 to fix Linux compilation with the existing `rust-ini` dependency. The lock file was generated by Cargo; some existing Windows dependency references were also resolved again and still need Windows validation.
- Exclude Linux threads from both process discovery and resource refresh so their shared memory and CPU usage are not counted repeatedly. A regression test starts a real native thread and verifies that it is excluded.
- Build and check the application on Ubuntu 22.04, then upload a `.deb` as a GitHub Actions artifact. This workflow does not publish a release.

## Download a test package

1. Open this repository's **Actions → Linux Beta** workflow.
2. Select a successful run for `linux/beta`.
3. Download the `Cardbe-linux-beta-<commit>` artifact and extract its `.deb` file.
4. On a compatible Ubuntu/Debian test system, install the actual downloaded file with `sudo apt install ./<package-name>.deb`.

Each push to `linux/beta` starts the workflow. An artifact is available only after all checks and packaging succeed, and is retained for 14 days. GitHub sign-in may be required to download it.

The workflow also declares `workflow_dispatch`, but GitHub requires a manually dispatched workflow to exist on the default branch. While this file exists only on `linux/beta`, use its push-triggered runs. See [GitHub's manual workflow documentation](https://docs.github.com/en/actions/how-tos/manage-workflow-runs/manually-run-a-workflow).

## Build locally

Use the toolchain and dependencies in [development.md](development.md), including Node 22, the project's pinned pnpm/Vite+ toolchain, Rust, WebKitGTK 4.1 and the app indicator development libraries. Initialize the pinned submodule before building:

```sh
git submodule update --init
vp install --frozen-lockfile
rustup target add wasm32-unknown-unknown
cargo install wasm-tools --version 1.259.0 --locked
vp run check
vp run test
vp run tauri build --bundles deb -- --locked
```

With the default Cargo target directory, the package is written to `src-tauri/target/release/bundle/deb/`.

## Validation scope

The Linux fixes have previously passed isolated Linux builds, resource accounting tests and Xvfb desktop smoke tests. Those checks do not establish complete desktop support. Check this branch's Actions run for its own clean build and package result.

Real X11/Wayland desktops, tray behavior, notifications, input methods, deep links and installation/upgrade behavior still need validation. Windows remains the primary platform; Linux packages are beta test artifacts. Keep a backup before trying a beta build with existing personal data.
